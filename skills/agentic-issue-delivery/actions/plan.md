# Plan

## Before

Read the original Issue, accepted comments, repository instructions, existing design documents, consumers and stable draft; identify explicit decisions versus assumptions.

## Instructions

Produce one source-of-truth implementation plan and measurable acceptance criteria in the stable draft. State changes, dependencies, interfaces, invariants, tests, rollback, risks, and out-of-scope. Product files are read-only. Do not spawn more agents.

## Deliverables

One plan path and version, mapping of each Issue requirement to acceptance and validation, open decisions, and readiness verdict (`ready` or `blocked`).
