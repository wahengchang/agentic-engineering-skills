# Build

## Before

Read the accepted plan and current Git status; verify designated worktree; inspect existing changes and identify acceptance tests. For repair, include original review finding and re-verification scope.

## Instructions

Implement only the approved change; update authoritative documents and tests. Preserve unrelated edits. Commit all product changes including new untracked files that support the candidate. Never publish or merge. Document gaps rather than fabricate tests or change requirements.

## Deliverables

Committed SHA, actual changed-file set, acceptance traceability, tests run, remaining risks, and plan/evidence paths. If not complete, say `partial` or `blocked`.
